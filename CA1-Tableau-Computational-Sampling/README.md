
# Langevin Dynamics Sampling and Tableau Visualizations

This repository contains the implementation for Data Science Assignment 1. The project is divided into two primary tasks: implementing a complex sampling algorithm (Langevin Dynamics) from scratch using Python, and creating an interactive, data-driven storytelling dashboard using Tableau to analyze real-world Airbnb data in New York.

##  Main Objectives

1. **Langevin Dynamics Sampling (Python):** Understand and implement the Langevin Dynamics sampling algorithm. Compute the score function for a probability distribution (where the normalization constant is unknown) and use it to sample from a 2D Bivariate Gaussian Distribution.
2. **Algorithm Evaluation:** Compare the samples generated from the custom Langevin Dynamics implementation against standard library sampling methods using statistical tests.
3. **Data Storytelling (Tableau):** Analyze geographic Airbnb datasets to create a structured narrative. Design interactive dashboards to uncover trends such as geographic price distributions, popularity through reviews, and the relationship between room types and pricing.

##  Core Concepts Explored

* **Score Function & Langevin Dynamics:** Deriving the gradient of the log probability density function to bypass unknown normalization constants and implementing iterative sampling using injected Gaussian noise.
* **Statistical Comparison:** Evaluating distributions using visual comparisons (heatmaps, quivers) and statistical tests (Kolmogorov-Smirnov test).
* **Interactive Dashboarding:** Utilizing KPIs (e.g., Average Price, Total Reviews), dynamic filters (price range, neighborhood groups, reviews per month), and parameters to create user-driven data exploration tools.
* **Geospatial & Correlational Analysis:** Mapping coordinates to evaluate density and utilizing scatter plots and bar charts to find correlations between availability, price, and customer reviews.

##  Key Results

### Part 1: Statistical Sampling (Python)

* **Sampling Convergence:** The custom Langevin Dynamics algorithm successfully traced trajectories and converged to approximate the target Bivariate Gaussian distribution, with the score function pointing directly toward the distribution modes.
* **Method Comparison:** Statistical testing confirmed that the samples drawn using Langevin Dynamics closely matched those generated by NumPy's highly optimized `multivariate_normal` function. Limitations were noted for multi-modal distributions (like Mixture of Gaussians) where the algorithm can get stuck in local modes.

### Part 2: Airbnb Data Insights (Tableau)

* **Geographic Dominance:** Analysis revealed that Manhattan and Brooklyn contain the vast majority of the Airbnb listings, with the northern parts of the city proving to be the most popular based on review density.
* **Pricing Dynamics:** "Entire Homes" consistently command higher average prices across all neighborhoods, whereas "Shared Rooms" are the most budget-friendly. The highest volume of listings falls into the lower price ranges, indicating strong market demand for cheaper accommodations.
* **Availability & Seasonality:** Scatter plot analysis showed **no direct correlation** between price and availability. Furthermore, availability does not heavily affect the number of reviews per month, suggesting that certain popular rooms may be designed for specific seasonal peaks but maintain overall high demand.
* **Conclusion:** Room type and neighborhood location are the two most significant factors dictating both the pricing and the overall popularity (review count) of an Airbnb listing.
