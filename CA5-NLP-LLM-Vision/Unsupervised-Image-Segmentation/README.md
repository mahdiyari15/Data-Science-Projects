# ⚽ Task 4: Unsupervised Image Segmentation Using Clustering

## 📌 Project Overview

Image segmentation divides an image into meaningful parts by assigning labels to individual pixels. While highly accurate, supervised segmentation requires expensive pixel-level annotations. This project explores an unsupervised approach, using clustering algorithms to segment football players from a pitch image. The task involves extracting meaningful pixel features, applying clustering methods (K-Means, DBSCAN, Agglomerative), filtering noise, and merging segments to isolate the players.

## 🗂️ Dataset

* **Images:** 50 randomly sampled frames from a football match.
* **Annotations (`instances_default.json`):** Ground-truth COCO format segmentation masks used solely for final evaluation.
* **Preprocessing:** Images were downscaled by a factor of 1/8 to prevent memory exhaustion and optimize computational speed.

## ⚙️ Methodology & Pipeline

### 1. Feature Engineering

Pixel clustering heavily depends on the extracted features. We developed two distinct feature pipelines:

* **Hybrid Hand-Crafted Features:**
* **Color:** LAB color space components.
* **Spatial:** Normalized (X, Y) pixel coordinates.
* **Edge:** Sobel gradient magnitude to detect boundaries.
* **Texture:** Local Binary Pattern (LBP) to capture patterns.
* *Weights:* Features were scaled using `StandardScaler` and multiplied by specific weights (`spatial=0.3`, `edge=1.5`, `texture=1.0`).

* **Deep Semantic Features (HRNet):**
* Extracted high-level feature maps from a pre-trained **HRNet** model.
* Concatenated with normalized (X, Y) pixel positions.

### 2. Clustering Algorithms

Tested three distinct clustering algorithms on the extracted features to group similar pixels together:

* **K-Means:** Evaluated using the Elbow Method and Silhouette Score. The optimal number of clusters was determined to be $K=3$.
* **DBSCAN:** A density-based algorithm that automatically handles noise (assigning `-1`). Tuned with parameters `eps=0.6` and `min_samples=50`.
* **Agglomerative Clustering:** A hierarchical method grouped using Ward's linkage.

### 3. Post-Processing (Filtering & Merging)

Raw clustering often results in noisy fragments (e.g., the pitch being split or players broken into pieces). A cleanup pipeline was applied:

* **Size Filtering:** Discarded clusters that were too small or too large using a threshold, isolating the player-sized regions.
* **Morphological Operations & Merging:** Used `cv2.dilate` and Connected Components analysis to merge fragmented clusters that were close together, yielding a clean binary mask isolating the players. Centroids were calculated for each isolated player.

### 4. Evaluation

The final binary masks generated by the unsupervised pipeline were compared against the ground-truth COCO annotations.

* **Metrics Used:**
* **Dice Coefficient:** $\frac{2 \cdot |A \cap B|}{|A| + |B|}$
* **Intersection over Union (IoU):** $\frac{|A \cap B|}{|A \cup B|}$

* The deep HRNet feature pipeline demonstrated superior robustness and accuracy compared to the hand-crafted features.
